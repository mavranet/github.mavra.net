# Mavra.Net

Türkiye'nin sohbet ve chat platformu.

Mavra.Net; web tabanlı sohbet, mobil sohbet ve farklı konulardaki sohbet odalarıyla insanların bir araya gelmesini sağlayan bir platformdur.

## 💬 Platform

- Sohbet odaları
- Mobil sohbet
- Web tabanlı chat
- IRC sohbet
- Farklı konularda sohbet kanalları
- Yeni insanlarla tanışma ve arkadaşlık
